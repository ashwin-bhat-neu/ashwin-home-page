# Personal Home Page

A front-end only personal website built with plain HTML, CSS and ES6 modules.
The visual language is built from trapezoids, hard edges and a muted palette.

## Structure

- `css/` stylesheets
- `js/` ES6 modules
- `images/` icons and pictures

## Scripts

```sh
npm install
npm start
npm run lint
npm run format
```
