Subsystems

What is running here

canvas / 2d

Lattice field

A grid of trapezoids whose top edges are driven by a sine wave. Cells near the pointer brighten. The geometry is rebuilt on resize and the loop stops when the tab is hidden.

  • requestAnimationFrame
  • seeded jitter

text

Scrambler

The phrase in the heading resolves one character at a time out of a stream of noise, then holds before the next phrase. The final text is in the markup, so it reads correctly without scripting.

  • deterministic
  • no layout shift

pointer

Parallax tilt

These cards rotate toward the cursor. The angle is written to CSS custom properties and the transform itself lives in the stylesheet, so motion can be disabled without touching the code.

  • custom properties
  • fine pointers only

input

Command palette

Ctrl K opens a filterable command list built on the native dialog element, so focus trapping, the backdrop and dismissal come from the platform rather than from script.

  • <dialog>
  • arrow keys

Provenance

Where this page came from

Home and Work were written by hand, in plain CSS, with the layout worked out in the browser. This page was generated by a language model, given the same palette and the same trapezoid geometry to work from, and then read through and corrected by hand before it shipped.

It is kept here as a comparison. The machine reaches for density, motion and instrumentation; the hand-made pages reach for white space and short sentences. Both are the same six colours.
